# Explorer les composants

1. Appelle `list_categories` pour voir ce qui existe.
2. Appelle `search_components` avec les mots-clés de la demande (français ou anglais).
3. Présente 3 à 5 résultats max : nom, id, une ligne de description.
4. Propose d'intégrer celui qui convient avec la skill `ui-build`.
